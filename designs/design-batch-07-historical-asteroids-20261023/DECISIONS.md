# Design decisions

23 October 2026

## Current review state

The user gave positive visual feedback on Batch 06 and requested the remaining historical asteroid designs. Batch 07 contains **17 proposed defaults and two historical alternatives**, all awaiting visual feedback. The prior inventory is a preserved planning snapshot; this new packet records design progress without rewriting that snapshot.

Vesta U+26B6 remains the existing default. U+1F777 is the new historical hearth alternative. Parthenope U+1CEC4 is the proposed fish-and-star default; U+1F77A is its lyre alternative. The separately encoded historical Astraea and Hygiea forms from Batch 06 are reused unchanged. No OpenType set number is assigned.
