# Sources and outline provenance

Accessed 23 October 2026.

| Source | Role |
|---|---|
| [Zane B. Stein, Thoughts on Centaur Symbols](https://www.zanestein.com/about_symbols.html) | Displayed forms, selected attributions and competing conventions |
| [Stein, Provisional Centaur Symbols](https://www.zanestein.com/provisional.htm) | Named examples and limits on provisional-symbol status |
| [Stein, Centaur Font Glyph Chart](https://zanestein.com/CentaursFontGlyphs.pdf) | Six-page visual form catalog, including Bienor update; local font keys are not Moira mappings |
| [Centaur Research Project](https://centaurs.robertvonheeren.de/menu/home1.shtml) | Context for the extended-centaur research group; not a Unicode or Moira calculation authority |
| [JPL SBDB API documentation](https://ssd-api.jpl.nasa.gov/doc/sbdb.html) | Number/name identity evidence only |
| Existing Moira master inventory and earlier design packets | Scope, stable semantic IDs, carried decisions and unchanged controls |

The source pages and chart are retained for internal reference with their notices. Selected browser screenshots and rendered PDF pages support visual inspection. No source image, external font or reference outline is included in the new master SVGs. No font binary is downloaded or parsed.

All ten studies use new Moira coordinates authored from observed symbol structure. The underlying conventions are modern attested forms, with known attributions and uncertainty recorded in [RESEARCH.md](RESEARCH.md) and [glyphs.json](glyphs.json). They are not presented as newly invented Moira concepts or as universally official symbols.

Chariklo's source GIF was displayed on a white browser background for inspection. The Thereus, Hylonome and Elatus source details were viewed at enlarged display sizes. These research captures are not contour traces. Final public review sheets contain only original Moira drawings and unchanged earlier Moira controls.
