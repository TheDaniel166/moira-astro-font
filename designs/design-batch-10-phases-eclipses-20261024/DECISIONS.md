# Batch 10 design decisions

| Decision | Draft 01 choice |
|---|---|
| Scope | Ten newly drawn character forms plus one solar-eclipse composition |
| Phase diameter | Common 630-unit outer diameter, centered at (500, 500) |
| Phase rim | 60-unit stroke on a 285-unit center radius; New Moon is solid |
| Crescent/gibbous terminator | 145 × 285-unit ellipse, chosen optically for chart sizes |
| Quarter boundary | Straight center division, with the common circular rim |
| Waning forms | Exact source mirrors of the corresponding waxing forms, with their own correct character identities |
| Filled circles | Original cubic paths, avoiding an observed small-size analytic-circle raster seam in local Chromium |
| Occultation | Filled 235-unit-radius disk and 60-unit round-ended diagonal stem |
| Lunar eclipse | Two filled 175-unit-radius disks and a 60-unit connecting stem |
| Solar composition | Unchanged Moon, new occultation, unchanged Sun; 135-unit clear ink gaps and 2190-unit source advance |
| Theme behavior | Fixed glyph geometry in light and inverse proofs; no physical illumination claim |
| Existing controls | Moon, Sun, conjunction and opposition preserved exactly |
| Encoding | Ten existing Unicode identities; multi-character solar composition; no PUA or ssXX allocation |
| Font integration | Deferred to a separately requested build after visual review |
| Native models | No calculation or model changes; contact availability remains data |

All new visual forms remain proposals for owner review. This packet does not mark the old inventory's planning fields as rewritten or complete.
