# Batch 11 design decisions

| Decision | Draft 01 choice |
|---|---|
| Scope | Seven character studies; no extra alternate family or font rebuild |
| Element motif | Preserve the own Trine triangle exactly for Fire and use it as the shared family component |
| Element stroke | Existing 60-unit round-cap, round-join construction |
| Air/Earth bar | 670-unit span, centered at y=500; whole-family width matches the triangle base |
| Downward forms | Exact vertical reflections of Fire/Air around the source-cell center |
| Fixed star | Five filled points, 340-unit outer radius and 150-unit inner radius; 24-unit rounded-tip stroke |
| Comet head | Open 150-unit center-radius ring with 54-unit stroke |
| Comet fan | Three 54-unit graphic strokes with separated far ends; no physical tail geometry claimed |
| Asterism | One six-ray asterisk above two; 44-unit strokes and clear gaps between clusters |
| Similar existing forms | Preserve Earth body, Sextile, Varda, Juno and Occultation; show labeled comparisons |
| Homography | Fire and Trine share a shape while retaining separate character identities |
| Mapping | Seven final assigned Unicode characters; Comet FE0E sequence documented for later integration |
| Feature access | Proposed tokens are metadata only; no PUA, ssXX or substitutions allocated |
| Font/model state | Existing TTF/WOFF2 and native calculations unchanged |

The master record meanings and source qualifications are retained. Counts and object rows in the context specimen are labeled typography examples, not calculated chart data.
