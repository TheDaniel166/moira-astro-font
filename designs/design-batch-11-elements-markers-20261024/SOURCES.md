# Source register

Accessed or verified 24 October 2026. Reference files are internal research inputs. The new masters and review sheets contain only Moira-owned vectors.

| ID | Primary source | Supports | Limits |
|---|---|---|---|
| unicode-17-final | [UnicodeData](https://www.unicode.org/Public/17.0.0/ucd/UnicodeData.txt) and [NamesList](https://www.unicode.org/Public/17.0.0/ucd/NamesList.txt) | Final assigned names and identities for all seven records | Does not prescribe Moira outlines or computational doctrine |
| indiana-alchemy | [Newman, Walsh, Kowalczyk and Hooper, L2/09-037](https://www.unicode.org/L2/L2009/09037-alchemy.pdf), Table 2, PDF page 12 | Documented four-element triangle/bar forms | Proposal-era temporary code positions are not mapping authority |
| indiana-guide | [Chymistry of Isaac Newton symbol guide](https://newton.dlib.indiana.edu/page/symbols) | Scholarly reference for the elemental forms | No source font data are imported; historical usage is not a universal glyph rule |
| unicode-17-reference-structure | [Alchemical chart](https://www.unicode.org/charts/PDF/Unicode-17.0/U170-1F700.pdf), [General Punctuation chart](https://www.unicode.org/charts/PDF/Unicode-17.0/U170-2000.pdf), and frozen [Miscellaneous Symbols chart](references/Unicode17-Miscellaneous-Symbols.pdf), each PDF page 2 | Reference structures and explicit version-17 chart context | Shapes are not prescriptive; no chart outlines are extracted |
| unicode-17-text-presentation | [Emoji variation sequences](https://www.unicode.org/Public/17.0.0/ucd/emoji/emoji-variation-sequences.txt) | Registered Comet + FE0E text sequence | Not evidence that the current font already implements the new character |
| moira-inventory | [Frozen selected records](references/planned-elements-markers.json) | Scope, exact meanings, contextual marker roles and priorities | Planning provenance is not approval of new visuals |
| moira-controls | [Frozen own-glyph controls](references/prior-controls.json) | Unchanged Trine, physical Earth, Sextile, Varda, Juno and Occultation drawings | Existing body/aspect/event semantics remain intact |

Local `*-reference.png` and `alchemy-proposal-elements.png` files are PDF research renders. They are not new Moira art or embedded specimen contents. Poppler warned about unavailable fallback fonts when rendering the old proposal; the relevant element rows remain visible and were cross-checked against the final version-17 chart. No dependency or reference-font installation was performed.

[Input provenance](input-provenance.json) records exact file origins and hashes. The Unicode data retain their [license](references/UNICODE-LICENSE.txt). No public distribution license for the Moira font is selected here.
