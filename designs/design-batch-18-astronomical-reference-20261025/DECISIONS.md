# Batch 18 design decisions

25 October 2026 - original visual-review proposals

| Meaning | Proposed construction | Text companion |
|---|---|---|
| Galactic center | One open spiral curling inward | GC |
| Supergalactic reference | Three separate points between open curved sides | SGref |
| North celestial pole | Horizontal plane with upper stem and solid endpoint | NCP |
| South celestial pole | The same plane with lower stem and endpoint | SCP |
| North ecliptic pole | Sloping plane with upper-left normal stem and endpoint | NEP |
| South ecliptic pole | The same plane with lower-right normal stem and endpoint | SEP |
| Geocentric | Earth circle-cross within open origin corners | Geo |
| Heliocentric | Sun circle-dot within the same corners | Hel |
| Barycentric | Three-spoke hub within the same corners | Bar |

All nine use 1,000-unit source cells and 60-unit round strokes. Pole markers have radius 90; origin hub/cluster details use explicitly recorded radii. Source review cells use the prior packet's 1.08 scale and -50-unit optical offset. These are review-cell placements, not new compiled-font advances or side bearings.

The origin frame is the same exact drawing in all three origin proposals. The celestial and ecliptic plane bars are exact shared constructions within each pair. Every pole stem is normal to its schematic bar; each north/south pair matches on a 180-degree geometry sampling grid. The endpoints distinguish polarity; the plane-bar angle distinguishes the family. The chosen slope has no physical-angle meaning.

The GC spiral uses one open contour; it should remain distinguishable from a closed circle-dot Sun. It resembles the general spiral vocabulary witnessed in the 2016 reproduced table, but is not presented as an exact historical reconstruction. The other proposals are commissioned Moira conventions; no historical set of nine is claimed.

The SGref construction is a graphic cluster mnemonic, not a picture of M87, a count of galaxies or a model of attraction. The registry keeps its reference selection unresolved and marks qualification as required. The M87 example documents one source-specific astrological use. The generic source inventory name and fallback remain intact.

The center-of-mass hub is also a mnemonic. It does not imply equal masses or three physical objects. Bar requires a system qualifier; the solar system is merely the displayed example. Geo and Hel refer to origin, while axis orientation and other calculation policies remain separate metadata.

All previous source controls are frozen. The two lot controls are explicitly the approved Fortune circle-cross and circled-S Spirit, taken from their own archival source records. Their defaults are unchanged. No drawing in an older packet is edited or replaced.

At 14 px, the pole balls, separated SGref dots and origin corners are fine detail. Labels/legends are recommended there. At 24/32 px, the machine checks sample both expected paint and intended blank areas, alongside manual proof review. These checks do not establish unaided semantic recognition. Full names remain available at every size.

Review does not select character access, make the proposals font entries, revise original priorities, install a font or authorize publication. Any later integration should retain the metadata distinctions and separately verify shaping, encoding and compiled-font optical placement.
