From guide to chart

Use the mark.

In a website

Load Moira Astro for the symbol run. Direct Unicode characters work normally. Tokens need discretionary ligatures; the slashed-zero alternate needs the zero feature.

Keep a readable name or accessible label beside the mark. Add the chosen model and formula to the chart data when those distinctions matter.

In Microsoft Word

Choose Moira Astro for the symbol run. Paste a Unicode character directly, or enable discretionary ligatures for an exact token. Where listed, use the hyphen-free Word alias; it selects the same existing form.

For the slashed zero, enable the OpenType slashed-zero feature for the base character. An application that does not expose a required feature may need a different supported route.

Characters, models and historical forms

A Unicode route identifies encoded text and its drawing. The named context, lunar model, lot formula and historical witness remain separate information. Related forms preserve those distinctions.

The source notes identify historical reconstructions, chart adaptations and original Moira symbols. Preview size is a review choice; historical forms generally need their name and witness at 32 px.
