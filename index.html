Use and source

Direct characters work normally. Token runs require discretionary ligatures; all 132 Word compatibility aliases remain optional. See the entry map, alias list, validation record and source notices.

The complete editable source is source/MoiraAstro-Regular.ttx. Build it with python -B build.py using the pinned dependencies. Symbols never select a native calculation model or a lot formula.
